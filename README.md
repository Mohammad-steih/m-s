# 💍 Muhammad & Aseel — Wedding Invitation

A simple and elegant **Arabic RTL wedding invitation website** for Muhammad & Aseel.

### ✨ Features

* Responsive design
* Arabic RTL layout
* Wedding & Henna event details
* Countdown timer
* Interactive calendar
* Google Maps locations
* Smooth animations
* No frameworks or backend
